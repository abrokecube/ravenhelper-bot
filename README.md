# ravenhelper-bot
Twitch bot that interacts with the Ravenfall API

Requires Python 3.12+ and `uv`

## Setup
1. Create and configure a `.env` file. Example in [.env.example](./.env.example)
2. Run `uv run basic_setup.py` and authorize using the bot's twitch account
3. Exit basic_setup and then start the bot

The default prefix for the bot is "`?`"
